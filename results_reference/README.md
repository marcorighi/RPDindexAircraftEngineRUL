# Reference results

This directory contains a compact, frozen subset of the outputs used to verify
the numerical results and figures reported in the manuscript.

Included:

- `01_indices/manifest.json`: provenance for canonical progressive RPD generation.
- `02_plot_data/`: exact plotting CSV files and figure-selection/provenance JSON.
- `03_figures/`: vector PDF manuscript figures.
- `05_tables/`: final numerical CSV tables and analysis provenance manifests.
- `06_logs/`: retained execution log for the canonical RPD-generation stage.
- `07_models/RUL_best_model_metadata.json`: metadata for the selected model.
- `CHECKSUMS.sha256`: SHA-256 digest of every retained reference file.

Intentionally omitted because they are large or mechanically reproducible:

- `04_results/01_indices/PM_train_RPD_progressive.csv.gz`;
- per-engine compatibility files under `04_results/01_indices/by_engine/`;
- compressed temporal-shuffle null distributions;
- full out-of-fold/intermediate feature datasets;
- high-resolution PNG duplicates of the vector PDF figures;
- `RUL_best_model.joblib` (its SHA-256 remains recorded in provenance).

The omitted files are regenerated by the documented pipeline. The original
`PM_train.csv`, `PM_test.csv`, and `PM_truth.csv` files are not redistributed;
their reference hashes are stored in the repository-level `DATA_SHA256.txt`.

## Path normalization

The numerical results are unchanged. For the public repository only, absolute
local filesystem paths in JSON manifests/logs are replaced by stable
repository-relative paths or `<PROJECT_ROOT>`.

Where a manifest contains the SHA-256 of another manifest, the hash recorded
during the scientific run is preserved in an `original_*_sha256` field and a
`public_reference_*_sha256` field is added for the normalized public copy.
